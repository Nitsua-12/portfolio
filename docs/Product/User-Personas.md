# User Personas

Two personas, in priority order per [[../Vision/Project-Vision|Project Vision]]. Both are early sketches based on Discovery — worth revisiting once real traffic/feedback exists.

## Primary: The Entry-Level Hiring Manager

Screens candidates for junior/entry-level web developer roles or internships. Busy, sees a lot of bootcamp-template portfolios, and has learned to distrust polish that isn't backed by substance — a slick site with vague project descriptions is a yellow flag, not a green one.

**What they're actually checking for:**
- Can this person explain their own code under questioning? (Why every project here must be real, per [[../Vision/Project-Vision|Project Vision]])
- Do they understand fundamentals, or just prompt an AI and hope?
- Is there evidence of judgment — knowing *when* to use AI and when to think it through themselves?
- Will they be a reasonable teammate? (Communication, humility, coachability — Austin's own words from Discovery: curiosity, patience, willingness to learn)

**What would make them stop scrolling:** a project with a real, specific origin story (not "I built a todo app to practice React") and a case study that shows actual decisions and trade-offs, not just a finished screenshot.

**What would make them bounce:** generic buzzword copy, unexplained tech-stack name-dropping, or a claimed skill level that doesn't match the actual code quality.

## Secondary: The Small-Business Freelance Client

A business owner (landscaping, local service, etc. — see the [[../AI-Workflow/Decision-Log|Decision Log]] note on the herbert-west-landscaping example that clarified this persona by contrast) who wants a site built and cares about outcomes — more traffic, more clients, clear communication — not implementation details.

**What they're checking for:** does this person communicate clearly, deliver what they say they will, and seem trustworthy with money and deadlines. Technical depth matters far less here than reliability signals.

This persona is secondary by design (see [[../Vision/Project-Vision|Project Vision]]) — the site should not dilute its primary hiring-manager message to chase this audience, but shouldn't actively repel it either.
